# 角色设计详细规则

### D. 角色视觉 DNA：十二个设计维度

| 维度 | 必须落实的判断 | 常见失误 |
| --- | --- | --- |
| 身份 | 一句话说明他是谁、处境是什么 | 只有“霸气、神秘、高级”等形容词 |
| 种族与解剖 | 头部、躯干、四肢和行为属于同一物种逻辑 | 猪妖退化成普通人戴猪鼻子 |
| 剪影 | 缩小后仍可区分的主体轮廓 | 全员宽肩、尖刺、披风、大腰带 |
| 比例 | 头身、胸腹、四肢和重心有明确关系 | 每个角色都变成同一肌肉英雄 |
| 面部 | 骨相、年龄、五官关系与情绪共同建立性格 | 网红脸、仙侠手游脸、统一精致美人脸 |
| 发型与毛发 | 发际线、长度、颜色、方向与材质稳定 | 同一角色跨图换发色或干湿状态 |
| 服装 | 可理解的穿着层次、连接与活动空间 | 装饰很多，却看不出衣服怎么穿 |
| 材质 | 主要材质有光泽、厚薄与磨损差异 | 皮肤、皮革、金属全部像塑料 |
| 色彩 | 主色、辅助色、少量强调色有主次 | 局部各自鲜艳，整体没有视觉中心 |
| 标志物 | 少量能够解释身份或能力的关键道具 | 随机挂满符号，谁都能用 |
| 姿态 | 身份与性格体现在重心、手势和视线 | 全部正面站立、同角度持武器 |
| 镜头与背景 | 角色识别优先，景别服务当前任务 | 环境和特效吞没面部与道具 |

不要强行把十二个维度全部展开成给用户看的长表。它们是设计判断与自检依据，输出长度由任务决定。

### E. 识别点、创新与差异化

先保留 1–3 个最重要的身份锚点，再选择少量真正改变角色感觉的创新方向。锚点可以是种族体态、发型、独特道具、服装结构或行为，不一定是装饰。

把创新落实为看得见的变化。例如“古老修行者进入未来”可以表现为袍服裁片与轻量连接件的结合；“失势的天界战士”可以表现为失配的旧装备、保留的礼仪动作和疲惫的眼神。不要只替换“赛博、东方、暗黑”等风格词。

检查三类重复：**同轮廓、同零件、同性格**。系列角色要在其中多个方面出现可见差异，不能只换主色。既定的角色 DNA 不为了追求差异而随意改变。

传统人物的辨识不依赖把所有象征物同时塞进画面。先保证最关键的形象成立，再决定其他符号是否需要出现。

### F. 写实、面部与物种结构

默认以电影级写实为目标：真实骨相、可信皮肤与毛发、自然光影、具有重量的衣物和道具。写实描述的是呈现与物理可信度，不是要求所有角色都变成人类。

人形角色以脸宽、颧骨、下颌、眼眶、鼻翼、嘴部、年龄痕迹和轻微不对称区分身份。避免用同一套大眼、尖下巴、极小鼻翼与光滑皮肤塑造所有人物。

妖怪与兽人先锁定物种结构。完整猪妖、熊妖或狮妖的口鼻、耳朵、颈肩、腹部、手足与毛发应构成一个整体；不能只改头部，其余全部沿用普通健美人类。

当用户要求保持上传人物时，保存其身份特征。面部差异化用于新设计，不应成为擅自换脸的理由。用户指定写实以外的风格时，调整表现方式，同时保留身份与结构约束。

### G. 服装、材质与细节密度

先确定内层、主体衣物、承重或连接结构，再加入身份配件。布料受重力影响，厚薄不同产生不同褶皱；硬质构件不得无故穿进身体，饰物要有连接位置。

优先使用少量主要材质建立对比，例如粗织布与深色皮革、骨质与黑化金属、白发与暗色衣料。不要让所有表面都出现相同刻纹、亮边、裂痕和油光。

把细节集中在视觉中心和身份关键区，保留较完整的安静面。用户说“干净”时，优先减少随机碎饰、纹理噪点和无差别锐化，不要同时抹掉结构与材质差异。

磨损必须有原因：高接触位置磨亮、衣摆局部磨耗、旧修补出现在受力或破损处。不通过全身污渍、满布锈迹与大量破布来替代真实感。

“太华丽”先减少重复雕花、金边和无功能首饰；“太素”先加强比例、材质对比或核心道具，不直接增加全身装饰密度。

### H. 科技元素与题材边界

科技化是可选方向。只有用户或项目要求时才加入，且优先围绕角色能力、身体使用方式、武器或服装连接展开。

轻科技可以从局部关节、眼部装置、武器接口、鞋足或薄型连接结构进入。必须说明它是什么、位于哪里、如何连接，而不是只写“加入一些机械感”。

保留主体服装与种族辨识，避免用通用外骨骼、全身霓虹、重复机械腰带取代角色设计。发光或大体量机械只有在当前设定需要时使用。

东方神话、西方哥特、现代现实与轻奇幻分别采用对应的造型语汇。跨文化融合需要明确的创作意图，不默认给西方角色加经文、佛珠、天庭装甲，也不默认把东方角色改成西方骑士脸。

### I. 构图、动作与光线

根据任务选景别：看脸用头肩或胸像，看服装用三分之二身，看整体剪影和道具用全身。不得在用户要求完整武器时仍裁掉关键部分。

优先使用能读清脸、轮廓与材质的主光，明暗层次可以强，但身份关键信息不能被黑暗或特效掩盖。写实不是必须低曝光，电影感也不是必须加入烟、火花和浓雾。

单角色设计默认低信息密度背景，常用 1–2 个环境提示即可。叙事场景可以增加环境，但应服务人物关系与行为。

动作要能落地：脚部有受力关系，手能够真实握住道具，衣物跟随姿态，武器长度与拍摄角度一致。不同角色的性格通过动作区分，不只依靠表情形容词。

画幅服从用户要求。没有指定时可建议：单角色展示 3:4，全身三视图或表情板 16:9；既有项目约定优先，不把建议写成不可更改的限制。

新角色资产默认无文字、无信息栏。用户要求海报题字、红印章或 Logo 时再加入；不得从风格参考中自动复制不属于当前任务的文字。

### J. 同一世界与多角色设计

先写一个简短的世界共性：时代、材料工艺、技术程度、色彩环境和服装体系。再为每个角色确定不同的身体比例、面部、主轮廓、核心道具和行为。

| 共性需要一致 | 差异需要可见 |
| --- | --- |
| 材料的制造方式与旧化程度 | 身高、胸腹比例、肢体长度 |
| 技术水平与连接逻辑 | 年龄、骨相、五官关系 |
| 同一阵营的少量视觉线索 | 服装轮廓、露肤区域、重心 |
| 同一场景中的光线和空间尺度 | 武器、标志物、姿态和视线 |

双人图要明确主次、前后和关系，避免两个人各自像独立海报。用户要求群像时可以重排构图，但不能随意改动已确认人物的脸、服装和物种。
